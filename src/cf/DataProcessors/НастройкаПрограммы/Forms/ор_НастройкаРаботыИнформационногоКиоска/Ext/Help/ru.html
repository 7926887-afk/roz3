Настройка параметров

Форма настройки параметров вызывается в подсистеме "Настройка и администрирование" из меню «Маркетинг» выбором пункта «Настройка работы информационного киоска».


Раздел «Настройки отображения информации в информационном киоске»

В этом разделе настраивается отображение элементов информационного киоска.

  • Акции. В информационном киоске становится возможным просматривать информацию по акциям, которые проходят по магазине.
  • Информация по карте. Если флаг установлен, то в информационном киоске будет возможно просмотреть информацию по дисконтной карте покупателя.
  • Информация о магазине. В информационном киоске становится возможным просматривать страницу о магазине.
  • Корзина. Если флаг установлен, то при работе в информационном киоске возмжно будет оформлять заказ.
  • Остатки в других магазинах. Если флаг установлен, в информационном киоске можно просмотреть остатки по другим магазинам.

 

Раздел «Настройка параметров киоска»

В этом разделе настраиваются параметры отвечающие за поведение киоска.

  • Заполнение каталога информационного киоска. Ложь - в каталоге информационного киоска будет отображаться содержимое справочника Номенклатура, Истина - отображать справочник Прайс-лист.
  • Выход из режима информационный киоск. По выбранной регистрационной карте будет осуществляться выход из информационного киоска.
  • Время бездействия. Время, по истечении которого, киоск вернётся в состояние равносильное его первому запуску. Если значение равно 0, то киоск будет обновляться каждые 300 сек (=5мин).
