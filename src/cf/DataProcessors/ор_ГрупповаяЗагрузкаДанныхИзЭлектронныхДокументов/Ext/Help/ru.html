Обработка "Групповая загрузка данных из электронных документов"

С помощью этой обработки можно выполнить групповую загрузку данных из электронных документов. Для выполнения загрузки необходимо выбрать настройки  в таблице и нажать на кнопку "Выполнить загрузку". Таблица настроек заполняется на основании регистра сведений "Настройки групповой загрузки данных из электронных документов".

Имеется возможность сохранить значения выбора для настроек с помощью кнопки "Сохранить настройки". При открытии формы флаги выбора в таблице настроек заполняются автоматически сохраненными ранее настройками. Для каждой строки настройки сохраняется история загрузки. После выполнения загрузки ее результаты по каждой строке настройки можно посмотреть в списке на странице "Настройка загрузки". Список позволяет выполнить отбор выводимых сообщений по статусам. Для этого используются флаги: "Помимо ошибок выводить замечания" и "Помимо ошибок выводить сообщения". Полная история всех загрузок отображается на закладке "Журнал групповой загрузки".
