Обработка "Мониторинг цен Росздравнадзора".

Назначение

Обработка предназначена для загрузки данных о товарах Росздравнадзора в прайс-листы поставщиков, сопоставления данных с номенклатурами информационной базы и выгрузки сведений о ценах и остатках для передачи их в Росздравнадзор.

Формы

  • Форма. Может работать в трех режимах. В режиме «Загрузка данных» производится чтение данных о товарах поставщика из файла (актуальный файл для загрузки сведений о товарах хранится на сайте Росздравнадзора http://mols.roszdravnadzor.ru/) и перенос этих данных в регистр сведений «Прайс-листы поставщиков», в режиме «Выгрузка данных» выполняется выгрузка данных об остатках и ценах. В режиме «Сопоставление данных» производится сопоставление загруженных данных с номенклатурами информационной базы. Режим «Сопоставление данных» доступен после загрузки сведений о товарах.

Дополнительная информация

    Реквизиты:

    • Поле ввода «Контрагент». Элемент справочника «Контрагенты». Поставщик, для которого будет осуществлена загрузка, сопоставление или выгрузка данных.
    • Поле ввода «Прайс-лист». Элемент справочника «Прайс-листы поставщиков». Прайс-лист поставщика, в который будет осуществлена загрузка данных о товарах, и по данным которого будет выполнено сопоставление и выгрузка данных.
    • Поле ввода «Файл данных». Строка. Реквизит доступен в режиме «Загрузка данных». Файл загружаемых данных.

Таблица загрузки содержит следующие колонки:

    • Поле ввода «Уникальный ID ЛС». Тип: «Число», может изменяться пользователем вручную. Уникальный идентификатор лекарственного препарата в системе мониторинга цен поставщика. При использовании этого поля препарат будет определен по нему и значения остальных полей (ID ЛС, ID производителя и ID упаковщика) будут игнорироваться.
    • Поле ввода «ID ЛС». Тип: «Число», может изменяться пользователем вручную. Идентификатор лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «ID производителя». Тип: «Число», может изменяться пользователем вручную. Идентификатор производителя лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «ID упаковщика». Тип: «Число», может изменяться пользователем вручную. Идентификатор упаковщика лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «Наименование ЛС». Тип «Строка». Наименование лекарственного средства в системе мониторинга цен поставщика.
    • Поле ввода «Дозировка ЛС». Тип «Строка», изменяется пользователем. Дозировка лекарственного средства по данным поставщика.
    • Поле ввода «Форма выпуска». Тип «Строка», изменяется пользователем. Форма выпуска лекарственного средства.
    • Поле ввода «Производитель ЛС». Тип «Строка», изменяется пользователем. Производитель лекарственного средства.
    • Поле ввода «Максимальная цена производителя». Тип «Число», изменяется пользователем. Максимальная цена производителя лекарственного средства.
    • Поле ввода «Штрихкод». Тип «Строка», изменяется пользователем. Штрихкод лекарственного средства, зарегистрированный в системе мониторинга цен поставщика.

Таблица сопоставления содержит следующие колонки:

    • Поле ввода «Номенклатура». Тип: справочник «Номенклатура». Номенклатура информационной базы, сопоставляемая с товаров поставщика.
    • Поле ввода «Код Росздравнадзора». Тип: «Число». Код Росздравнадзора выбранной номенклатуры.
    • Поле ввода «Единица измерения». Тип: справочник «Единицы измерения». Базовая единица измерения сопоставленной номенклатуры.
    • Поле ввода «Номенклатура поставщика». Тип: «Строка» Наименование номенклатуры поставщика.
    • Поле ввода «Уникальный ID ЛС». Тип: «Число». Уникальный идентификатор лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «ID ЛС». Тип: «Число». Идентификатор лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «ID производителя». Тип: «Число». Идентификатор производителя лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «ID упаковщика». Тип: «Число». Идентификатор упаковщика лекарственного препарата в системе мониторинга цен поставщика.
    • Поле ввода «Штрихкод». Тип «Строка». Штрихкод лекарственного средства, зарегистрированный в системе мониторинга цен поставщика.

Таблица выгрузки содержит следующие колонки:

    • Поле ввода «Номенклатура». Тип: справочник «Номенклатура». Номенклатура информационной базы, данные о ценах которой будут выгружены в систему мониторинга цен поставщика.
    • Поле ввода «Характеристика номенклатуры». Тип: справочник «Характеристики номенклатуры». Серия номенклатуры информационной базы, данные о ценах которой будут выгружены в систему мониторинга цен поставщика.
    • Поле ввода «Количество». Тип: «Число». Количество остатков номенклатуры в базовых единицах измерения.
    • Поле ввода «Цена производителя». Тип: «Число». Цена производителя в валюте регламентированного учета.
    • Поле ввода «Цена закупки». Тип: «Число». Цена закупки с учетом НДС в валюте регламентированного учета.
    • Поле ввода «Розничная цена». Тип: «Число». Розничная цена с учетом НДС в валюте регламентированного учета.
    • Поле ввода «Документ поступления». Тип: документ «Приходная накладная». Документ поступления товара.
    • Поле ввода «Поставщик». Тип: справочник «Контрагенты». Поставщик товара.
