Сверка остатков МДЛП

Обработка предназначена для сверки состояний упаковок базы данных с информацией, полученной от ИС МДЛП.
В шапке обработки надо указать организацию МДЛП и место деятельности.
По кнопке Получить упаковки МДЛП в табличную часть загружается информация об упаковках из личного кабинета ИС МДЛП и подтягиваются данные об упаковках из базы.
В табличной части обработки отражаются sgtin, GTIN и код препарата по ЕСКЛП. Для каждого sgtin выводятся две строки. В первой строке – данные, полученные от ИС МДЛП, во второй – данные об упаковке из базы. По разным причинам эти данные могут не совпадать. По кнопке Заполнить по данным МДЛП информация об упаковках в базе данных приводится в соответствие информации из ИС МДЛП.
Используя фильтр, можно получить информацию о конкретной упаковке и проанализировать ее состояние в базе данных. Например, это поможет выяснить причину отклонения уведомления с кодом «Некорректное состояние», когда статус упаковки в базе данных отличается от статуса в ИС МДЛП.

По кнопке Загрузить из ТСД можно проверить сразу состояние нескольких упаковок, заранее отсканированных в ТСД. Для приведения статусов упаковок в состояние, соответствующее статусу в системе маркировки по кнопке Заполнить по данным МДЛП корректируется статус упаковки в базе. По кнопке Записать необходимо сохранить изменения в базе.
Обработкой Сверка остатков нельзя изменить статусы упаковок в базе данных, которые находятся в статусе В резерве или К поступлению, т.к. эти статусы являются промежуточными и возможно, по ним ожидается квитанция об окончании операции.
При начале работы, если обмен с МДЛП производился в другой программе, и на балансе организации в личном кабинете МДЛП есть упаковки маркированных ЛП, обработкой Сверка остатков можно записать их в базу данных.
