Справочник "Классификатор АТХ"

Анатомо-Терапевтически-Химическая (АТХ) система классификации (ATC) - рекомендованная Всемирной Организацией Здравоохранения для международных исследований использования лекарственных препаратов. Это система классификации активно используется в фармакоэкономике для учета лекарственных средств, а также применяется при проведении клинических исследований для оценки сопутствующей терапии.

Используется для элементов справочника «Номенклатура».
