Виды контактной информации

Справочник содержит информацию о  собственных организациях и организациях контрагентов, зарегистрированных в системе МДЛП.

Для добавления собственной организации надо по кнопке Добавить выбрать опцию Собственная и ввести Идентификатор и Секретный код из личного кабинета МДЛП. При загрузке данных организации необходимо отметить Места деятельности, список которых будет выведен, по которым будет вестись учет в этой базе.

Для добавления организации контрагента необходимо по кнопке Добавить выбрать опцию Контрагент и ввести ИНН,  ОГРН или регистрационный номер участника МДЛП и запросить данные контрагента. При загрузке контрагента надо отметить Места деятельности, с которых будут поступать лекарственные препараты.
