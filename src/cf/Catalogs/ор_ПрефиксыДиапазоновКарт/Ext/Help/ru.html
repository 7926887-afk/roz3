Префиксы диапазонов карт

Справочник используется для регистрации соответствий префиксов информационных карт и их типа(штриховой или магнитный) для последующего предоставления скидки по картам по условию "По префиксам номеров карт".

Если при вводе кода обнаружено пересечение между возможностью получения скидки по префиксу номера и определением информационной карты(номенклатуры, серийного номера подарочного сертификата) система предложит пользователю выбрать требуемое действие
