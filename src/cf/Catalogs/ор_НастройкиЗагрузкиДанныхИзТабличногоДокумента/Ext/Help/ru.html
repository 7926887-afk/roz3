Справочник "Настройки выгрузки/загрузки данных"

Назначение

Справочник хранит настройки для выгрузки или загрузки данных. Выгрузка реализована для справочников (целиком) и табличных частей для отдельных документов. Загрузка реализована только для табличных частей отдельных документов. Настраивать алгоритм заполнения рекомендуется опытным пользователям. При заполнении не выполняется контроль целостности данных.

В веб-клиенте справочник доступен только для просмотра!

Реквизиты

  • Вариант использования. Ссылается на перечисление «Варианты использования настройки». Выгрузка или загрузка данных.
  • Тип объекта. Ссылается на перечисление «Типы прикладных объектов». Документ, справочник, регистр сведений.
  • Объект. Тип значения: «Строка». Объект для которого предназначена данная настройка.
  • Табличная часть. Тип значения: «Строка». Табличная часть объекта (доступна только при выборе документа).

Дополнительная информация

    Элементы управления режима загрузки:

    • Флажок «Ручная нумерация колонок». Используется для ручной нумерации колонок табличного документа, в случае, когда состав колонок табличного документа отличается от отмеченных загружаемых реквизитов.
    • Флажок «Поиск по прайсу поставщика».  Если флажок взведен, осуществлять поиск номенклатуры по прайс-листу поставщика.
    • Поле ввода «Первая строка данных табличного документа». Определяет, с какой строки табличного документа загружать элементы.
    • Поле ввода «Количество необрабатываемых строк». Определяет количество строк табличного документа снизу, которые не будут загружаться.
    • Поле выбора «Кодировка». Кодировка файла.
    • Поле ввода «Табуляция». Определяет символ разделяющий реквизиты при загрузке текстовых документов.
    • Гиперссылка «Развернуть табличный документ» и поле выбора файла для интерактивной настройки загрузки. Гиперссылка включает/отключает режим интерактивной настройки нумерации колонок в соответствии с выбранным файлом для загрузки. При включенном режиме становится доступным выбор файла.
    • Поле ввода «Действие с загружаемым файлом». Доступные действия с файлом.
    • Флажок «Использовать внешний модуль преобразования файла».  Если флажок взведен, то загрузка в электронный документ будет осуществляться из файла путем его преобразования обработкой в табличный документ.
    • Поле ввода «Обработка преобразования файла». Используется только для режима загрузки с помощью внешнего модуля преобразования файла. Определяет, какой обработкой следует преобразовывать файл в табличный документ.

    Для загрузки справочников  «Номенклатура» и «Характеристики номенклатуры» доступны настройки загрузки дополнительных реквизитов и сведений:

    • Флажок «Загружать дополнительные реквизиты и сведения». Определяет необходимость добавления в таблицу загружаемых реквизитов дополнительных реквизитов и сведений для дальнейшей настройки их загрузки.
    • Флажок «Только общие для всех видов номенклатуры». Ограничивает состав добавляемых реквизитов и сведений только теми, которые заданы как общие для загружаемых справочников.
    • Поле «Вид номенклатуры». Задает список видов номенклатуры, по которым будет отобран состав дополнительных реквизитов и сведений.

    Таблицы настроек

    • Флажок «Пометка». Используется для отметки, какие реквизиты следует загружать (для режима загрузки в регистр сведений обязательна отметка всех измерений регистра и период).
    • Поле ввода «Представление реквизита». Тип «Строка», не изменяется пользователем.
    • Поле ввода «Описание типов». Тип «Описание типов», изменяется пользователем, но имеет ограничение типов из графы «Ограничение типов».
    • Поле выбора «Режим загрузки». Доступные значения "Искать", "Вычислять", "Устанавливать".
    • Поле ввода «№ Колонки табличного документа». Для режима «Ручная нумерация колонок табличного документа».
    • Поле ввода «Значение по умолчанию». Тип задается в поле «Описание типов».
    • Поле выбора «Искать по» (имя представления). Используется для поиска значения реквизита ссылочного типа по представлению в выбранном виде (например: по коду, наименованию, артикулу).
    • Поле выбора «Связь по владельцу». Выбирается пользователем для реквизита ссылочного типа, имеющего владельца, содержит указание на колонку связи по владельцу в составе загружаемых реквизитов или на непосредственного владельца.
    • Поле выбора «Связь по типу». Выбирается пользователем для реквизитов типа «План видов характеристик», содержит указание на колонку связи по типу в составе загружаемых реквизитов или на ссылку элемента связи по типу (в основном типа «План счетов ссылка»).
    • Поле ввода «Элемент связи по типу». Изменяется пользователем для реквизитов типа «План видов характеристик», содержит номер элемента связи по типу (номер субконто).
    • Поле ввода «Выражение». Выражение для режима «Вычислять».
    • Поле ввода «Режим поиска». Может иметь 2 значения: по равному значению и по похожим словам. Режим поиска по похожим словам может быть выбран для строковых реквизитов загрузки, а также для реквизитов ссылочного типа, если для их поиска выбран строковый реквизит.

    Команды

    • Актуализировать настройки. Используется для обработки нескольких настроек - в случае, если сохраненные настройки загрузки не соответствуют текущим объектам метаданных конфигурации, то по результату выполнения обработки они автоматически будут изменены на актуальные.
