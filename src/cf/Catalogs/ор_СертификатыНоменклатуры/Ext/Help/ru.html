Справочник "Сертификаты номенклатуры"

Назначение

Справочник Сертификаты номенклатуры предназначен для ведения реестра документов, сертифицирующих продукцию, и печати присоединенных изображений.

Параметры

Длина наименования: 1500.

Иерархический.

Реквизиты

  • Дата начала. Тип значения: «Дата». Дата начала действия сертификата.
  • Дата окончания. Тип значения: «Дата». Дата окончания действия сертификата.
  • Бессрочный. Тип значения: «Булево». Признак того, что действие сертификата бессрочно.
  • Орган выдавший документ. Тип значения: «Строка». Орган выдавший сертификат.
  • Тип сертификата. Перечисление "Типы сертификатов номенклатуры".
  • Номер. Тип значения: «Строка». Номер указывается в соответствии с номером документа.

Способ вызова

Вызывается из командной панели справочников "Номенклатура", "Характеристики номенклатуры".

Работа с печатными формами

При печати из документов предусмотрено две команды - печать изображений действующих сертификатов и печать реестра действующих сертификатов. Сертификат считается действующим для документа, если его срок действия распространяется на дату проводки документа-родителя.
При печати реестра действующих сертификатов документы подбираются для каждой позиции, и нумерация строк совпадает с нумерацией строк в документе-родителе, например, расходной накладной.
