Зоны таможенного контроля МДЛП

Справочник содержит список зон таможенного контроля, необходимых для оформления уведомлений по импорту-экспорту лекарственных препаратов.
По кнопке Добавить в форме справочника надо ввести регистрационный номер участника МДЛП или ИНН организации, номер свидетельства о включении в реестр ФТС и код таможенного органа. По кнопке Запросить данные ЗТК в программу загрузится список ЗТК, зарегистрированных для данной организации в МДЛП. После отметки нужных ЗТК надо нажать кнопку Сохранить данные ЗТК.
