Номенклатура, отсуствующая в базе

Механизм позволяет сократить количество справочников в информационной базе. Создание справочников происходит в момент формирования заказа через побор товаров, перейдя на вкладку "Номенклатура вне базы".

Механизм включается настройкой Администрирование -> Продажи -> Заказы покупателей -> Создавать номенклатуру при заказе

Механизм позволяет создавать номенклатуру в следующие моменты времени:

  • При ручном формировании документа "Заказ покупателя" в беке через закладку "Номенклатура вне базе" в подборе товаров
  • При формировании заказа в РМК и альтернативном РМК

Для работы механизма необходимо заполнить следующие объекты в конфигурации:

  • Регистр сведений "Номенклатура, отсутствующая в базе"- хранит информацию по номенклатуре, доступной к заказу в разрезе наименований поставщика и вида номенклатуры. Для заполнения данного регистра предусматривается b
  • Справочники "Шаблоны формирования номенклатуры" и "Шаблоны формирования характеристик"(при использовании характеристик) - хранят информацию по реквизитам справочников. Для того, что реквизит заполнился при создании его имя необходимо добавить в список реквизитов. Если указать значение реквизита, то при создании он заполнится автоматически, в противном случае создастся форма со списком реквизитов для заполнения.
