Регистр сведений "Рецептурные прописи"

Назначение

Регистр предназначен для отражения состава лекарственных форм по номенклатурным позициям в соответствии с рецептурными прописями.

Параметры

Периодичность: По позиции регистратора.

Режим записи: Подчинение регистратору.

Измерения

  • Лекарственная форма. Ссылается на справочник «Номенклатура». Лекарственная форма.
  • Составляющая. Ссылается на справочник «Номенклатура». Номенклатура - составляющая лекарственной формы.

Ресурсы

  • Количество лекарственной формы. Тип значения: «Число». Количество единиц лекарственной формы.
  • Количество составляющей. Тип значения: «Число». Количество единиц составляющей лекарственной формы.

Реквизиты

  • Единица измерения лекарственной формы. Ссылается на справочник «Единицы измерения». Единица измерения лекарственной формы.
  • Единица измерения составляющей. Ссылается на справочник «Единицы измерения». Единица измерения составляющей лекарственной формы.
