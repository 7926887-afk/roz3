Настройки групповой загрузки данных из электронных документов

Регистр сведений "Настройки групповой загрузки данных из электронных документов" предназначен для хранения настроек загрузки информации поступающей от контрагентов в виде электронных документов. Данные настройки используются для выполнения загрузки в автоматическом режиме с помощью обработки "Групповая загрузка данных из электронных документов". Кроме того для каждой настройки есть возможность использования регламентного задания с указанием расписания. 

 

Измерения

  • Контрагент. Ссылка на справочник Контрагенты. Значение контрагента, для которого выполняется загрузка.
  • НастройкиЗагрузки. Ссылка на справочник НастройкиЗагрузкиДанныхИзТабличногоДокумента. Значение настройки загрузки данных из электронных документов.
  • Каталог. Строковое значение. Определяет каталог, в котором будет осуществляться поиск файлов для загрузки.

Ресурсы

  • ИспользоватьРегламентноеЗадание. Булево. Признак необходимости использования регламентного задания.
  • ДействияСФайлами. Строковое значение. Определяет действие с файлом после выполнения загрузки.
  • КаталогПеремещения. Строковое значение. Каталог, в который будет перемещен файл, если значение ресурса "ДействияСФайлами" предполагает перемещение.
  • ПроводитьДокументы. Булево. Определяет необходимость проведения документа после загрузки.
  • Наименование. Строковое значение. Наименование настройки.
