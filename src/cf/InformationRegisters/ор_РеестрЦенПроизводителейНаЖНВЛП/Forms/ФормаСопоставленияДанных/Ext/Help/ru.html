Форма "Сопоставление данных"

Назначение

Служит для сопоставления наименований лекарственных средств из реестра цен производителей на ЖНВЛП со справочником Номенклатура.

 

Способ вызова

Вызывается из командной панели действий формы списка регистра сведений "Реестр цен производителей на ЖНВЛП" (кнопка "Сопоставление данных").

Дополнительная информация

Сопоставление наименований лекарственных средств со справочником Номенклатура  выполняется автоматически при открытии формы. При этом первичное сопоставление номенклатур происходит по Номеру РЛС (для номенклатур он указывается при загрузке товаров с ИТС в регистре сведений Дополнительные параметры ЛС), в случае, если по этому номеру товар не найден - выполняется вторичное сопоставление по штрихкоду.

 Для тех элементов по которым не найдено соответствие, можно выполнить подбор вручную.
