Регистр сведений "Нормы естественной убыли"

Назначение

Предназначен для хранения данных по нормам естественной убыли для номенклатуры.

Параметры

Периодичность: Позиция регистратора

Режим записи: Подчинен регистратору

Измерения

  • Вид нормы. Реквизит является обязательным для заполнения. Вид нормы естественной убыли.
  • Номенклатура. Реквизит является обязательным для заполнения. Ссылается на справочник «Номенклатура». Номенклатура, для которой указываем значение норму естественной убыли. 

Ресурсы

  • Значение нормы. Тип значения: «Число». Значение нормы естественной убыли.

Способ вызова

Из меню "Перейти" формы документа возможен просмотр движений, сформированных этим документом.

Документы, порождающие движения: «Установка норм естественной убыли».
