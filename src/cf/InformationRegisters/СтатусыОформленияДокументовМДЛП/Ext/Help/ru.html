Статусы оформления документов МДЛП

В регистре хранятся записи о статусах оформления уведомлений по учетным документам, по которым предполагается оформление уведомлений для МДЛП.
Статус оформления может принимать значения
  • оформлено, 
  • не оформлено,  
  • частично оформлено, 
  • есть ошибки оформления
  • не требуется.
При статусах "частично оформлено" и "есть ошибки оформления" требуется сравнить данные в документа учета и уведомлениях, созданных на их основании.
