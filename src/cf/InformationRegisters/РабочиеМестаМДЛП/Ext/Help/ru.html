Рабочие места МДЛП

В регистре хранятся настройки для использования РВ.
Для каждой организации МДЛП, места деятельности и рабочего места, созданного в настройках подключаемого оборудования, с которого будут оформляться уведомления о выдаче для оказания мед.помощи и отпуска по льготному рецепту надо настроить Рабочее место МДЛП.


Если для рабочего места текущего сеанса, указанного в настройках подключаемого оборудования не настроено рабочее место МДЛП, то при отправке уведомления появится сообщение "Сообщение в МДЛП не может быть передано. Для места деятельности организации <идентификатор места деятельности> не настроено подключение".
