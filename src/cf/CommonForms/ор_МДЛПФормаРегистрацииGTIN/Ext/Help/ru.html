Сервис регистрации GTIN предназначен для упрощения задачи добавления записей по GTIN в регистр сведений "Штрихкоды" при приемке новых товаров в уведомлениях МДЛП.

Запускается из документов "Уведомление о приемке лекарственных препаратов", "Уведомление об оприходовании", "Уведомление о повторном вводе в оборот маркированных товаров" И "Уведомление о перемещении лекарственных препаратов" с типом операции "Приходный ордер".

В сервис из документа попадают GTIN, по которым нет существующих записей в регистре. При заполнении таблицы сервиса производится автоматическое заполнение колонки "Для характеристики" на основании существующих данных в регистре. Данная колонка используется для определения, как будет происходить регистрация GTIN. Если флаг в установлен, то регистрация будет производиться в разрезе характеристики, если не установлен, то будет добавлена запись с пустой характеристикой.
