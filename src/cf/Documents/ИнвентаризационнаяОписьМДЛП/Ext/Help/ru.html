Инвентаризационная опись МДЛП


При инвентаризации МДЛП происходит сравнение и анализ состояний упаковок ФГИС МДЛП, регистра сведений Упаковки МДЛП и фактического наличия потребительских упаковок.

Загрузка данных об упаковках (МДЛП) производится из Витрины товаров по SGTIN личного кабинета системы маркировки.

У пользователя, который проводит инвентаризацию МДЛП, в личном кабинете ФГИС МДЛП должны быть добавлены следующие права доступа: MANAGE_EXPORT_TASKS и SHOWCASE_SGTIN.

Для каждой отдельной упаковки будут выведены результаты анализа и предложены варианты дальнейших действий пользователя для актуализации соответствия данным ФГИС МДЛП.

Во время проведения инвентаризации МДЛП пользователю нельзя проводить никаких операций с упаковками. Это сделано для исключения изменений статусов упаковок во время анализа.

Важно! Инвентаризация проводится отдельно на каждом месте деятельности организации.

На первом шаге проведения инвентаризации создается документ Инвентаризационная опись, в котором по кнопке загрузите остатки нужно загрузить остатки упаковок из ФГИС МДЛП и регистра сведений Упаковки МДЛП.

По кнопке оформите инвентаризацию надо создать документ Инвентаризация потребительских упаковок МДЛП. К одной инвентаризационной описи можно оформить несколько таких документов.
