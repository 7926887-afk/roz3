Инвентаризация потребительских упаковок

Документ создается из документа Инвентаризационная опись.

У документа Инвентаризация потребительских упаковок МДЛП есть два режима заполнения данными: по остаткам и по факту.

Важно! После заполнения табличной части в одном режиме нельзя перезаполнять этот документ в другом режиме.

Если пользователь выбрал режим заполнения По остаткам, (рис.13.87) то производится заполнение документа остатками упаковок МДЛП и сопоставление с остатками базы. Далее пользователь сканирует (или загружает из ТСД) имеющиеся в наличии упаковки. Результат анализа рассчитывается динамически.

В случае заполнения документа По факту  расчет и заполнение результатов анализа выполняется по кнопке Заполнить после добавления упаковок, которые фактически есть на месте деятельности. Добавление упаковок возможно с помощью сканера (ТСД) или вручную. Анализ выполняется только для добавленных пользователем упаковок.

Перед заполнением По остаткам рекомендуется сделать отбор данных. Табличная часть документа имеет ограничение – не более 99999 записей.

Условия отбора желательно сделать более жесткими, чтобы в табличную часть попало удобное для работы количество упаковок. Например, можно отбирать упаковки одного лекарственного препарата или одну серию ЛП.

Для заполнения документа надо нажать кнопку Заполнить. После заполнения документа и сканирования упаковок, имеющихся в наличии, программа покажет пользователю результат анализа. Для детального просмотра описания результата инвентаризации и рекомендуемых действий можно дважды щелкнуть мышью по полю Результат анализа.

После заполнения документа рекомендуется сразу провести документ, чтобы другой пользователь не начал работу в программе с этими отобранными упаковками, т.к. при проведении документа упаковки резервируются.

По кнопке Проверить результаты (или по кнопке выполните проверку) пользователь переходит в форму для анализа и выбора рекомендуемых действий с упаковками.

Пользователь в этом окне анализирует, оставить предложенные программой действия или выбрать другие возможные действия на основании информации о реальной ситуации с упаковками.

После выбора пользователем конкретных действий по кнопке Подтвердить будет произведена сверка остатков для тех упаковок, где выбрано действие Выполнить сверку остатков.

Важно! После подтверждения сверки возврат статуса упаковок в информационной базе к исходному состоянию будет невозможен.

Для изменения действий сразу в нескольких выделенных строках можно воспользоваться кнопками Отобрать строки и Изменить выделенные строки 

После подтверждения результатов и проведения сверки остатков нужно оформить уведомления, если это требуется, после чего документ Инвентаризация потребительских упаковок МДЛП можно закрыть.
