Договор о приоритетной поставке

Документ Договор о приоритетной поставке служит для назначения приоритетов номенклатуры по поставщикам в случае установленного режима Использовать приоритеты поставщиков.

Чтобы настроить режим приоритетов поставщиков, нужно сделать следующее:

· Установить флажок Использовать приоритеты поставщиков на странице Запасы и закупки раздела Администрирование.

Список договоров о приоритетной поставке можно открыть по ссылке Закупки - Работа с поставщиками - Договор о приоритетной поставке.

Для удобства работы Пользователь может отфильтровать список заказов по поставщику и организации, выбрав нужные значения в соответствующих полях шапки списка. С помощью сервиса Найти, который запускается из командной панели списка, Пользователь может выбрать нужные договора, задавая поиск по значениям различных реквизитов.

Новый документ можно добавить с помощью кнопки Создать в командной панели списка.

Заполнение шапки документа

В шапке нового документа нужно заполнить следующие поля:

· Контрагент - поставщик, с которым заключается договор, выбирается из списка контрагентов;

· Организация, с которой заключается договор;

· Дата окончания действия договора;

Заполнение табличной части Товары

Для добавления товара в табличную часть нужно нажать кнопку Добавить (Insert) командной панели табличной части документа;

Для каждой товарной строки в отдельном поле указывается приоритет поставки.
