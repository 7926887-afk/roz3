Уведомление о повторном вводе в оборот маркированных товаров

Операция повторного ввода в оборот (схема 391) применяется как для возврата в оборот ранее выведенных из гражданского оборота ЛП, так и для перевода в статус, позволяющий осуществлять дальнейшие операции в ИС МДЛП с ЛП, ранее не введенных в гражданский оборот, а также ЛП, не подлежащих реализации. 
Повторный ввод ЛП в оборот может осуществляться только субъектом обращения, ранее осуществившим вывод этих ЛП из оборота, за исключением случая повторного ввода в оборот ЛП, ранее выведенных из оборота по причине списания при отгрузке ЛП в рамках закрытых контрактов (договоров). В указанном случае сведения о повторном вводе в оборот регистрирует субъект обращения, являющийся получателем таких ЛП. 
При оформлении уведомления требуется указать причину, по которой упаковка была выведена из оборота и причину возврата в оборот.
Упаковки, выведенные из оборота для оказания мед. помощи или отпущенные по льготному рецепту не подлежат возврату надлежащего качества.
Повторный ввод ЛП в оборот согласно настоящему разделу Паспортов процессов может быть применен в отношении ЛП: 
  •  ранее отобранных в рамках федерального государственного контроля (надзора), осуществляемого Росздравнадзором (тип 7); 
  •  ранее выведенных из оборота по причине списания (тип 1); 
  •  ранее выведенных из оборота в результате розничной продажи (только для недоброкачественных ЛП) (тип 9); 
  •  ранее выведенных в рамках отпуска по льготному рецепту (только для недоброкачественных ЛП) (тип 4); 
  •  ранее выданных для оказания медицинской помощи (только для недоброкачественных ЛП) (тип 5); 
  •  ранее выведенных из оборота в рамках экспорта (тип 10); 
  •  ранее выведенных из оборота в рамках вывоза ЛП на территорию государства-члена ЕАЭС (тип 8); 
  •  ранее выведенных из оборота в результате отгрузки незарегистрированному участнику (возврат от незарегистрированного участника) (тип 6); 
  •  ранее выведенных из оборота в целях клинических исследований (тип 11); 
  •  ранее выведенных из оборота в результате отпуска ЛП в аптеке по документам (только для недоброкачественных ЛП) (тип 12); 
  •  ранее выведенных из оборота в рамках экспорта ЛП вне территории Российской Федерации (тип 13); 
  •  ранее выведенных из оборота с типом вывода «продан в розницу» в рамках контрольной закупки (тип 9);
  •  ранее выведенных из оборота с типом вывода недостача (списание при инвентаризации) (тип 14); 
  •  ранее выведенных из оборота в результате перемещения в карантинную зону (тип 15); 
  •  ранее выведенных из оборота по причине списания при отсутствии информации согласно БП (тип 16); 
  •  ранее выведенных из оборота по причине отбора контрольных образцов в рамках процесса контроля качества/архивных образцов (тип 17).

Условия применения схемы 391 и причины отказа от регистрации повторного ввода в оборот системой маркировки описаны в Паспортах процессов на сайте честного знака.
